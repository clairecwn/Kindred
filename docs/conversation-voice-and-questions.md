# Companion voice and question policy

Kindred separates four decisions: what the user meant, which concern deserves attention, whether a question would help, and how the reply should sound. The language model writes the reply, while the saved dialogue state and reply critic enforce these decisions. The coefficients below are routing heuristics, not probabilities of a person's feelings.

## Voice

`buildVoiceProfile` reads the journal and recent **user** turns. It weights a substantial journal as a style prior and discounts very short turns, so a reply such as “huh” does not erase a user's established voice. It records casing, substantial message length, casual vocabulary, shorthand, stretched words, punctuation bursts, all-caps emphasis, laughter, emoji and playful comparisons. Singlish particles are one optional feature. A person can have a strongly informal style with no regional particles at all. These measurements describe writing habits; they are not age, identity, personality, or mood diagnoses.

For each message, observed counts are divided by weighted word count. The journal gets weight `0.7`; recent user turns get `min(1, words/14) × exp(-0.28 × turns_ago)`. A compact casual-evidence score combines informal-token rate, `0.6 ×` expressive rate, and `0.3 ×` shorthand rate. A separate evidence-confidence term is `1 - exp(-weighted_words/55)`; very thin evidence cannot force a style correction. These are transparent routing heuristics, not calibrated probabilities. A brief current message allows up to `0.3` weight from older, user-authored journal and chat style; a substantial current entry takes precedence. Explicit requests about how Kindred should speak are kept separately from inferred writing habits. The profile cache is rebuilt when those sources change or are deleted.

The writer receives the observed feature vector and short user-authored style examples. It follows current emotional tone: playful phrasing can be met playfully, while a serious or irritated turn gets a direct answer. `normaliseUserTextForUnderstanding` supplies a conservative secondary gloss for common shorthand and intentional lengthening, while raw text stays authoritative for topic evidence. Unknown slang stays untouched for contextual interpretation. The writer is instructed to keep intentional emphasis when natural and correct accidental spelling mistakes. The reply critic flags polished therapist language, a longer casual reply with too few observed texting cues for the user's writing rate, regional particles the user has not used, and strong slang inserted into a formal user's reply. This catches a token “damn” added to otherwise polished prose. A style revision preserves the selected topic and meaning. If that optional revision fails, a content-safe draft remains available.

The latest stress test exposed a structural mismatch: a casual opener followed by a formal “which moment hit you hardest?” interview frame. The critic now scores that question shape as voice drift for casual writing, and the opening-turn validator rejects incident-ranking menus when the topic policy has already selected a concern. The writer is guided to match how the user reacts and joins thoughts across **all** clauses, without repeating the same slang marker every turn. No fixed Singlish or Gen Z template is inserted. This is an inference-time style policy, not model training.

Regression cases cover an expressive friend-texting style without Singlish, a Singlish style, and a formal style. They check that short acknowledgements preserve earlier writing cues, unknown terms are not silently redefined, and extra regional particles are not inserted. The current code adapts prompting, memory and reply selection; it does **not** fine-tune a foundation model's weights. Fine-tuning would require consented, labelled examples and held-out evaluation across writing styles before deployment.

This approach draws on [linguistic style matching](https://doi.org/10.1177/026192702237953) and [lexical entrainment in conversational systems](https://aclanthology.org/2023.findings-emnlp.22/). [LLM dialogue research](https://aclanthology.org/2025.sigdial-1.16/) reports a gap between semantic and stylistic alignment, while a [2026 study](https://aclanthology.org/2026.eacl-long.34/) finds that models can also overfit a conversation's style. This is why the critic checks for both sterile formal drift and forced imitation. Work on [normalising social-media neologisms](https://aclanthology.org/D19-5555/) motivates keeping interpretation separate from output spelling. [ChatGPT memory](https://help.openai.com/en/articles/8590148-memory-in-chatgpt) and [Claude Styles](https://support.anthropic.com/en/articles/10181068-configuring-and-using-styles) publicly describe personalization, but their internal algorithms are not public; Kindred does not assume they use this design.

## Question value

The assessor can propose a follow-up only for an unresolved concern. It must name an exact quote supporting the question, the specific unknown it could resolve, and its purpose. It rates information gain `G`, relevance `R`, user effort `E`, repetition risk `P`, task coaching `T`, and whether the purpose is a coping/task/mood-lift/filler prompt `C`. The policy computes:

`U(q) = 0.9 G + 0.8 R - 0.65 E - 1.1 P - 1.4 T - 1.4 C - 1.1 M - V`

`M` marks an assessor-declared empty information gap; `V` penalizes repeatedly using the same question dimension without a reason. In live assessment, missing or ungrounded quote/gap/purpose data suppresses the question. A question is allowed only when `U(q) >= 0.85`, the answer is not already known, and the dialogue action allows a question. After the debrief policy selects a topic, the question score is rebound to that selected topic. The writer receives its grounded information gap in the response contract; this closes the previous gap where a budget was passed without the reason for the question. The final reply check also rejects task-readiness prompts and generic tiny-comfort questions. If no useful question is proposed, the writer offers a specific observation with room for the user to respond. This follows research on the different purposes and effects of [empathetic questions in social dialogue](https://aclanthology.org/2022.acl-long.211/). The weights and threshold are provisional and should be tuned on human-rated Kindred conversations.

After a substantive answer, the assessor checks for a genuinely unknown outcome or consequence on that thread. The dialogue contract asks the writer to use that gap when it is useful; otherwise the writer adds a grounded thought that keeps the thread open. This avoids turning the user's answer into a closed paraphrase while also avoiding a compulsory question after every turn.

## Topic coverage and transitions

The policy tracks an uncovered amount for every meaningful, open concern: `D_i = (salience_i + intensity_i) × unresolved_i × (1 - depth_i) × (1 - 0.5 × closure_i)`. Incidental details, declined topics and settled topics do not create coverage debt. The next thread is chosen by its `D_i`, a small bonus for an explicit user-supported link to the current thread, and recency. An explicit user redirect still wins immediately.

One short agreement does not move the conversation. If two low-information turns follow the same thread while another meaningful concern remains unvisited, the policy chooses `SHIFT` rather than `SOFT_CLOSE`. A substantive answer resets that streak and stays with the topic. The response contract supplies the old and new user quotes; the writer closes the current thought, then bridges to the next concern in a second paragraph. It must not invent a causal relationship between events. This is inspired by [dynamic topic tracking in long conversations](https://aclanthology.org/2024.inlg-main.43/) and [empirical work on topic transitions](https://aclanthology.org/2022.codi-1.12/), without importing their reported shift frequencies as a universal target. The thresholds are application heuristics that need user-rated calibration.

## Corrections and repeated choices

A brief answer to a prospective question is tracked as a proposed future activity. The assistant cannot describe it as completed or ask whether it already helped. A timing correction, confusion signal, or repeated choice raises repair priority and suppresses new questions. The first repetition calls for a brief repair; a further repetition after repair calls for a gentle landing. These signals affect the **dialogue action** only; the writer still generates the wording. The reply critic rejects unsupported completion claims, generic coping questions, journal recaps after short corrections, and interpretations that override the user's explicit choice.
