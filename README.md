# Kindred

Kindred is a wellbeing game prototype that combines journaling, emotional avatar feedback, social play, personal land building, and real-world activities.

## Current Prototype

- Interactive journal entries with local emotion interpretation.
- Editable animated 3D animal companion powered by Three.js.
- Zoomable social shopping street with shops, purchases, and player interactions.
- Interactive personal land with character movement and editable houses.
- Real-world activities on an OpenStreetMap/Leaflet map, including locally saved custom activities.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.
